## Clean-room statement

This repository was written from public, vendor-neutral sources only:

* the published eye-movement literature (e.g. Salvucci & Goldberg, 2000, for the
  velocity-threshold algorithm; Holm, 1979, for the multiple-comparison
  correction);
* general-purpose numerical and statistical libraries (NumPy, pandas, SciPy,
  statsmodels, pingouin, openpyxl, FastAPI);
* the *shape* of ordinary delimited-text exports, which is a de-facto
  interoperability format rather than a vendor asset.

The project deliberately contains **none** of the following:

* Tobii Pro SDK, DLLs, installers, headers, or any other vendor binary;
* vendor sample recordings, screenshots, logos, icons, fonts, or UI copies;
* code obtained by reverse-engineering a proprietary or undocumented file
  format;
* any trademark of Tobii AB, including in the names of files, endpoints, or
  user-visible labels.

Column names such as `Recording timestamp`, `Gaze point X`, `Validity left` or
`Eye movement type` are used only as *matching patterns* so that a researcher's
own export can be read without manual retyping. They are descriptive field
labels found in many eye-tracking exports, not copyrighted works, and the
loader accepts any alternative column names through explicit manual mapping.

## Data

All demonstration and test data shipped with this project is **100 % synthetic**
and generated by `gazera_core.synthetic`. It contains no participant data, no
real recording, and no vendor sample file. Users' own files are processed
locally and are never transmitted by the library or the web workbench.

stays usable without it. Install it only if your workflow already uses it.
